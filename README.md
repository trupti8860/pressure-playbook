# PRESSURE PLAYBOOK
### SupeRR Selector — Season 02

A responsive IPL pressure-performance scouting dashboard built using HTML, CSS and vanilla JavaScript.

## Project structure

PRESSURE-PLAYBOOK/
│
├── index.html
├── style.css
├── data.js
├── app.js
└── README.md

## Run the website locally

1. Make sure all five files are saved inside the same folder.
2. Double-click `index.html`.
3. The website will open in your browser.
4. Navigate using the sidebar.
5. Use the search boxes and dropdown filters to explore the shortlist.

An internet connection is required for the Google Fonts used in the design. The dashboard itself does not require an API or backend.

## Upload to GitHub

1. Sign in at https://github.com/
2. Click the `+` icon in the top-right corner.
3. Select **New repository**.
4. Repository name: `pressure-playbook`
5. Set visibility to **Public**.
6. Click **Create repository**.
7. Choose **Add file → Upload files**.
8. Upload the five files from this folder.
9. Click **Commit changes**.

Important: Upload the files directly into the repository's main/root folder. Do not upload an extra nested folder containing the files.

## Publish using GitHub Pages

1. Open the repository.
2. Select **Settings**.
3. Select **Pages** from the left sidebar.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main`.
6. Select folder `/ (root)`.
7. Click **Save**.
8. Wait for GitHub Pages to publish the website.

Your website link will look like:

https://YOUR-USERNAME.github.io/pressure-playbook/

Replace `YOUR-USERNAME` with your GitHub username.

## Dashboard features

- Overview and analysis summary
- Batter shortlist with search and eligibility filters
- Bowler shortlist with search and eligibility filters
- Pressure-performance statistics
- Methodology and eligibility explanations
- Responsive desktop and mobile layout

## Analysis scope

- IPL seasons: 2022–2026
- Match records identified: 371
- Matches with ball-by-ball data: 367
- Deliveries analysed: 87,673
- Pressure deliveries: 31,248
- Selected players: 20

## Important data notes

This dashboard presents the selected candidate shortlist from the IPL pressure-performance analysis.

Eligible ranks are relative to the eligible population in each discipline. Players who do not meet the minimum sample-size requirements are labelled provisional and are not assigned a rank.

The dashboard does not establish that any selected player is available for a future auction. Auction availability, retention status, budget and team composition must be checked separately.
